# KAIVO Whitepaper

## Vision and mission

Agents that work for people need money they can spend without supervision and a record anyone can read afterwards. KAIVO's vision is a balance that behaves like a wallet for machines: funded once, spent across many models, and always explainable.

The mission is to make that balance boring to operate. One unit, matched one-to-one with USDG. One routing layer that picks the model for each task. One ledger per agent.

## Roadmap

**Phase 1: Foundation.** Public site, live market board, record register, brand system.

**Phase 2: Balance.** kCASH issuance against USDG, deposit flows, spend ledger per agent.

**Phase 3: Routing.** Automated model selection across hundreds of models, tier pricing published.

**Phase 4: Reach.** Agent framework adapters, tool-protocol endpoint, additional networks.
